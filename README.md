Курсовой проект, выполненный на 4м курсе СПО. Загружен через 1C:EDT.
Разработка информационной системы для котокафе, которая предназначена для управления его деятельностью и взаимодействия с разработанной базой данных.
Включало в себя этапы: Анализа предметной области, проектирования и разработки базы данных, разработки приложения, тестирования и отладки, разработки документации.
Позволяет вести учет товара, подопечных котокафе, работать с поставщиками на минимальном уровне. Предоставляет простую форму отчетности.
